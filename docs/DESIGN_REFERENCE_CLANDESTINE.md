# Referência visual — Clandestine Beauty Salon

## Fonte de referência

- Repositório: `Northstrix/clandestine-beauty-salon-landing-page-template`
- Licença declarada no repositório de origem: MIT.
- Uso neste projeto: **referência de composição e interação**, não importação cega do conteúdo de demonstração.

## O que foi absorvido como direção

- navegação escura e compacta com alto contraste;
- hero de forte presença visual;
- alternância entre blocos escuros e claros;
- serviços apresentados de forma editorial/listada, evitando grade SaaS genérica;
- fotografia em grande escala;
- microinterações discretas;
- ritmo visual inspirado em salão premium.

## Paleta adaptada para Vanessa Braz

A cor de destaque roxa do template de referência **não** foi copiada. O projeto usa uma interpretação própria:

- preto/vinho profundo;
- rosé queimado;
- blush/champagne;
- creme quente;
- dourado discreto apenas como apoio.

## Regra de conteúdo — disclaimer do template de referência

O template avisa que nomes, serviços, descrições, categorias, preços, equipe, depoimentos, produtos, endereço, contato, horários, reservas e demais dados comerciais são fictícios e existem somente para demonstração.

Por isso, **nenhum dado fictício do template deve ser transferido para Vanessa Braz**.

Neste projeto:

- dados confirmados podem ser exibidos;
- dados ainda não confirmados permanecem `PENDENTE_DE_CONFIRMACAO`;
- não criar equipe fictícia;
- não criar depoimentos fictícios;
- não criar produtos ou preços para preencher layout;
- não criar horários, endereço ou contatos demonstrativos;
- não apresentar uma simulação de checkout como transação real;
- booking real só deve afirmar sucesso após confirmação do backend;
- conteúdo jurídico continua sujeito à revisão humana antes de produção.

O disclaimer integral do template **não deve ser colocado como disclaimer do negócio real**, porque ele descreve a natureza demonstrativa do template de origem. Aqui ele funciona como regra de provenance: não herdar seus dados de demonstração.
